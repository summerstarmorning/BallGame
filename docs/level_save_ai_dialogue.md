# AI Dialogue Record

## Dialogue 1

User:
砖块要从 JSON 读，别再写死在代码里了，至少三关，而且 JSON 坏了也不能直接崩

AI:
可以把关卡系统拆成 `LevelLoader`，每关一个 JSON 文件。加载时先解析 `ball`、`paddle`、`bricks`，如果文件缺失、格式错误、或者 `bricks` 为空，就回退到默认布局并给玩家一个提示，而不是让游戏崩掉

User:
那存档怎么设计，后面要扩字段怎么办

AI:
运行存档单独放一个 `run_save.json`，先保存最关键的 `currentLevel`、`score`、`lives`。再加一个 `version` 字段，后面升级格式时可以按版本迁移，比如旧版只有 `level`，新版改成 `currentLevel`，加载时先兼容旧字段，再立刻重写成新格式

User:
继续游戏是自动进还是先问

AI:
启动时先检测存档，主菜单给出继续提示更稳。这样既满足读档要求，也不影响录屏时展示新开一局和继续存档两条路径
